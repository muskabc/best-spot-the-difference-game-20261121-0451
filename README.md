Spot the Difference — a complete browser game with two hand-drawn scenes (a Corner Café and a Park at Dusk), 8 hidden differences in each, a ticking timer, hints, a miss penalty, synthesized sounds, and a star-rated win screen. Both pictures are drawn in code with plain canvas 2D — no images, no network, no dependencies. Click a difference on either picture to mark it; find all 8 before the clock runs out, then move on to the next scene.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keys: `H` hint, `R` restart, `M` sound.
